# Simple Python Games

A collection of classic terminal games built with basic Python. Perfect for beginners and classroom projects.

## 🕹️ Games Included

### 1. Dungeon Quest (`main.py`)
A simple grid-based adventure game where you navigate a player (P) to the exit (X) while avoiding walls. 
- **Features**: Basic grid movement, score tracking, win/loss conditions.
- **Controls**: W (Up), A (Left), S (Down), D (Right) + Enter.

### 2. Arcade Snake (`snake.py`)
A refined version of the classic Snake game with pipeline-style visuals and a directional head.
- **Features**: Dynamic box-drawing characters, Apple spawning, coordinate collision detection.
- **Controls**: W (Up), A (Left), S (Down), D (Right) + Enter.

### 3. Number Guessing Game (`guessing_game.py`)
A classic guessing game where the computer picks a random number and the player has 10 attempts to find it.
- **Features**: Higher/Lower hints, attempt counter, student-friendly code.
- **Controls**: Numeric input + Enter.

## 🚀 How to Run
Make sure you have Python installed, then run any game using:
```bash
python <filename>.py
```

## 🛠️ Requirements
- Python 3.x
- Works on Windows, Mac, and Linux.
